# Project Title
Social Media Blog Application

## Project Description

This is a robust Social Media Blog Application built using modern microservices architecture and cloud-native technologies. The main purpose of this project is to provide a platform where users can register, log in securely, create and publish blog posts, edit or delete their own posts, and share content with other users.

The application is designed to simplify content sharing and user interaction while maintaining data security, scalability, and performance. It uses Spring Boot to develop backend microservices, Spring Cloud for service discovery and communication, Spring Data JPA for database operations, and AWS for cloud deployment and scalability. Spring Security and JWT-based authentication are used to secure APIs and ensure that only authorized users can access protected resources.

## Technologies Used

Spring Boot: Simplifies application development by providing production-ready applications with embedded servers.

Spring Cloud: Supports microservices communication, configuration management, and service discovery.

Spring Data JPA:Simplifies database interactions and provides efficient data persistence.
AWS: Enables cloud hosting, storage, deployment, and scalability.

REST APIs: Enable communication between clients and backend services through HTTP requests.

Spring Security: Provides authentication and authorization to protect application resources.

Basic Authentication: Supports simple authentication for API endpoints where appropriate.

JWT Authentication: Provides stateless, token-based authentication to securely validate users and control access to protected endpoints.

## Project Purpose and Target Users

The application is intended for bloggers, content creators, and general users who want to publish, manage, and share their ideas online. It demonstrates how to build a secure, scalable backend application using Java, Spring Boot, microservices architecture, REST APIs, and cloud technologies.
